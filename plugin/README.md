# Flat White UI 插件

TS3 的样式表改不了面板布局。这个插件用进程内 Qt 访问重排了主窗口的控件结构。

> 早期版本还做过"主频道整行染色"，因为观感不佳已移除；插件现在只负责布局。

## 它做什么

**内容优先布局（固定比例）**

```
+----------------------+-----------------------------------------+
| 频道树                |                                         |
|                      |                                         |
|----------------------|                聊天                     |
| 信息 / 个人资料        |                                         |
+----------------------+-----------------------------------------+
```

- 外层分隔器由纵向改为横向：聊天从底部升为右侧整幅主画布
- 内层分隔器由横向改为纵向：频道树在上、信息面板在下，合并成一条左侧竖栏
- 竖栏宽度固定 420px，频道树 / 信息面板高度固定 439 / 319（窗口内高 758）
- 窗口固定 940×901，不随上次关闭时的尺寸变化；窗口位置仍沿用客户端保存的位置（含副屏）
- 只翻转分隔器方向与尺寸，不重新挂载控件，切标签和退出都安全
- 切换服务器标签时，布局跟随当前可见标签

## Discord 式界面（浅色 / 深色）

聊天区与底部用户面板是自绘的；频道/成员列表则**直接用客户端原生的 `ServerTreeView`**
（原生模型、原生顺序、原生事件），只替换了行绘制：

```
+----------------+---------------------------+
| 服务器名        | # 频道名                   |
| 分类 ▾          |---------------------------|
|  ♪ 频道         |  聊天消息                  |
|   ○ 成员        |                           |
|  ♪ 频道         |                           |
|----------------|  [ 输入框 ]                |
| (头像) 名字     |                           |
+----------------+---------------------------+
```

- **原生频道树 + 自绘委托**
  - 列表数据、排序、展开状态、选中、拖拽和双击全部由客户端原生模型处理，
    成员进出/切频道立即刷新，没有轮询延迟
  - 委托按行类型重绘：服务器标题、分类/大区、带锁频道（喇叭 + 锁）、成员行
  - 成员不再画头像，只画一个 **11px 圆圈**：静默是灰色空心圈，说话时变绿色实心灯；
    说话状态通过 `ts3plugin_onTalkStatusChangeEvent` 即时驱动，不等心跳
  - 所有成员统一一个青绿圆点（`#0F766E`，表示在线且麦克风开启），离开时降低透明度；说话时圆点变为绿色，说完恢复青绿
  - 成员状态徽标（右对齐、扁平描边）：琥珀色月牙 = 离开，红色麦克风+斜杠 = 闭麦，
    红色扬声器+斜杠 = 扬声器静音；来自 `CLIENT_AWAY` / `CLIENT_INPUT_MUTED` / `CLIENT_OUTPUT_MUTED`,
    自己的静音状态在回调里即时刷新，其他人的状态由 600ms 轮询补齐
  - 成员名保留服务器组头衔（如 `[仙尊] 3ku`）；超长频道名直接裁剪，不再补省略号
  - 点击成员在右侧显示资料页；选中服务器时显示服务器横幅 + 服务器资料，
    选中频道显示频道简介；横幅只在服务器行被选中时出现
  - 当前频道高亮；双击频道切换、双击成员私聊、加密频道密码框都是客户端原生行为
- **底部用户面板**：自己的头像、状态点、昵称、离开/麦克风/扬声器三个可点开关；
  点麦克风直接切换静音（不再内置音量滑杆，音量在设置里调整）
- **右侧资料页**：服务器横幅只在选中服务器行时显示；选中频道显示频道简介；
  资料页不再附加客户端自动生成的大号状态图标
- **中间聊天**：顶部是自绘频道标题栏（`# 频道名 | 主题`），
  输入框改为 Discord 风格圆角灰底
- **现代化聊天**：频道聊天和私聊标签页的日志区由 `ModernChat` 覆盖为气泡列表
  （自己的消息右对齐、`#E3F1EE` 浅青底；他人左对齐 `#F2F3F5` 浅灰底；
  发送者、时间小字弱化；空状态居中提示）。气泡只覆盖日志矩形，输入框和标签栏不受影响；
  消息来自 `ts3plugin_onTextMessageEvent`，频道按服务器+频道、私聊按对端名称（兼容标签显示名差异）缓存历史；
  顶部自绘标题栏在私聊标签下显示对方名称与「私聊」，服务器标签下显示服务器名与「服务器」；
  服务器标签同样使用气泡视图，连接/断开、成员加入/离开/移动等事件以居中灰色系统行显示
- **戳一戳提醒**：别人戳你时，主窗口右上角浮出一张卡片，显示「谁 戳了戳你」和留言；
  连续被戳会累计次数。卡片不会自动消失，点击后关闭。同一事件仍会以红色系统行
  写进服务器事件流
- **原生工具栏**：启动时隐藏 `ImprovedToolBar`（离开、静音、订阅、人数、延迟、音量、头像），
  离开/静音/音量已并入用户面板；退出插件时恢复
- **窗口尺寸**：固定为 940×901，内部竖栏 420px、频道树/信息 439/319，右侧聊天列约 520px，
  窗口位置尊重客户端保存的位置（包括副屏），只在完全落在所有屏幕外时居中

频道树/成员数据仍来自原生模型；用户面板与状态徽标的数据来自官方插件 API：
`getClientList` / `getClientDisplayName` / `getClientVariableAsInt`。
点击成员/服务器/频道时，信息页作为悬浮层覆盖在聊天内容上（聊天标签栏保持可见，
点「‹ 聊天」或任一聊天标签返回）。悬浮层不加入 `QStackedWidget`，因此客户端的
标签切换和发送目标不会被插件改写。删除 DLL 即可完全恢复原布局。

## 深色模式

深色主题是独立的 `.ts3_style`（`flat_dark`），与浅色主题共享同一套结构和模板，
只换调色板。插件在启动时读取客户端当前的样式表文本：

- 包含 `flat_dark` → 深色；包含 `flat_white` → 浅色；
- 两者都取不到时退回到 `QPalette::Window` 的亮度（深色样式表会通过注释声明整套调色板）。

自绘控件（频道树委托、用户面板、气泡聊天、聊天标题栏、信息页顶栏）的颜色全部走
`discord::` 调色板，模式变化时 `applyPluginTheme()` 会重设样式并重绘。客户端自己的控件
由主题 QSS 负责，插件不改写。

Windows 窗口标题栏由 DWM 绘制，QSS 管不到。深色模式下插件对每个可见顶层窗口调用
`DwmSetWindowAttribute`：

- `DWMWA_USE_IMMERSIVE_DARK_MODE`（Win10 2004+ 为 20，旧版为 19）→ 深色标题栏；
- `DWMWA_BORDER_COLOR`（34）→ 深色窗口边框，避免 Win11 留下一条浅色描边；
- 对话框在 `Show` 事件里立即应用，心跳每 1.5s 兜底新窗口；浅色模式不做任何改动。

## 安装

```
dist/plugin/flatwhite_ui_win64.dll  →  %APPDATA%\TS3Client\plugins\
```

重启客户端生效。插件依赖客户端自带的 `Qt5Core.dll / Qt5Gui.dll / Qt5Widgets.dll`，
不需要额外运行库。

卸载：关闭客户端，删除该 DLL 即可。所有改动只在运行时生效，不会写入客户端配置。

## 实现要点

| 问题 | 做法 |
| --- | --- |
| 插件如何拿到 Qt 对象 | 插件是加载进 `ts3client_win64.exe` 进程的原生 DLL，链接同版本的 Qt 5.15.2 MSVC2019 x64，与客户端共享同一份 Qt 运行时 |
| 找到频道树 | `QApplication::allWidgets()` 里筛 `QTreeView` 且 `objectName() == "ServerTreeView"` |
| 新布局 | 找到包住树和信息面板的横向 `QSplitter`，把 `MainWindowChatWidget` 插入到两者中间 |
| 退出恢复 | `ts3plugin_shutdown` 里把聊天区放回原纵向分隔器并还原尺寸，避免污染客户端保存的窗口状态 |
| 线程安全 | `ts3plugin_init` 可能不在 GUI 线程，用后台线程检测 `QCoreApplication` 就绪后 `QMetaObject::invokeMethod` 抛回 GUI 线程 |
| 读取频道数据 | `ts3plugin_setFunctionPointers` 收到的 `TS3Functions` 表，按官方 SDK 头文件调用 |
| 替换频道树 | 在树所在容器的布局里追加自己的 `QScrollArea`，然后隐藏原树 |

## 构建

依赖：

- Visual Studio 2022 Build Tools（`C:\BuildTools`，需要 VC++ 工作负载 + Windows SDK）
- Qt 5.15.2 `win64_msvc2019_64`（`C:\Qt\5.15.2\msvc2019_64`）

```bat
plugin\tools\build.bat
```

产物：`plugin\build\flatwhite_ui_win64.dll`。

## 诊断日志

插件启动时会把控件树 dump 到：

```
%APPDATA%\TS3Client\flat_white_plugin.log
```

包含所有顶层窗口、树视图（模型类、委托类、列数、缩进）、分隔器层级与尺寸，
以及布局何时应用/还原。排查问题先看这个文件。

## 风险

- **版本绑定**：链接的是 Qt 5.15.2 msvc2019 x64。客户端升级 Qt 版本后插件可能加载失败或崩溃
- **崩溃影响整个客户端**：委托绘制在每次重绘时执行，任何异常都会让客户端退出，而不是只坏掉插件
- **布局改动是运行时的**：不写入配置；退出时还原；但强制结束进程（任务管理器）会跳过还原
- **仅 Windows x64**：DLL 是 MSVC x64 构建
